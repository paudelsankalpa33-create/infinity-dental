### Installation Steps
1. Open the SETUP executable file
2. Promped to allow the app to make changes to your device will appear.
3. Allow it by pressing **Yes** button
4. Installation page will be opened
5. Click on **INSTALL** button
6. Within a minutes you will be promped with **"Driver install success!""** message
7. Press **Ok** button and then cancel the installation page

This completes the driver installation steps on Windows.
